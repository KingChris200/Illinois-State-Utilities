# Message Style

Illinois State Utilities should sound like a real Discord bot written by real people.

## Default style

- Use a short, clear title.
- Say the main point in one or two sentences.
- Show only details the reader needs right now.
- Prefer normal words: `posted`, `ended`, `changed`, `ready`, and `offline`.
- Let the embed color and banner carry the visual style.
- Use member avatars where the message is about one person.
- Keep record IDs, scoring, analysis, and audit details in private logs.

## Avoid

- Repeating the same status in the title, description, and fields.
- Emoji in every heading or field.
- Phrases such as `successfully initiated`, `officially concluded`, `formally documented`, or `operational readiness`.
- Long introductions, congratulations paragraphs, and corporate closing statements.
- Extra logo thumbnails when a branded banner is already shown.
